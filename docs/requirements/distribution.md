# Distribution and open source

| ID      | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DIST-01 | Downloads from the project's release page: for Windows an archive; for Linux a package for the common package managers, which also installs the web view, and an archive for other distributions. Prerequisites: git 2.42 or newer, and the operating system's web view component (preinstalled on Windows 11; installed separately on Windows 10 and with the Linux archive). At start the app checks both and says clearly if one is missing or git is too old. A WSL distro's git is checked the same way when a repo in that distro is first opened.                   |
| DIST-02 | Releases are built by an automated pipeline from a tagged commit and published on the project's release page, with checksums. No hand-built binaries.                                                                                                                                                                                                                                                                                                                                                                                                                      |
| DIST-03 | No installer program and no auto-update in v1; the Linux package installs through the system's package manager. The app shows its version.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| OSS-01  | Source is public on GitHub under **BSD-3-Clause**. All dependencies have compatible licences.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| OSS-02  | A new contributor can build and run tests with the documented steps only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| OSS-03  | User docs: install, first start, editor setup, known limits (WSL, SSH passphrase without agent).                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| OSS-04  | Nothing in the app assumes the owner's setup: no fixed paths, editor, remote host, or branch names.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| OSS-05  | **Hard requirement: licence compliance.** No code, text or asset from another project enters the repo unless its licence is permissive (the dependency allow-list) and its notice ships with every release. Nothing is taken from copyleft (GPL, AGPL, LGPL) or source-available projects: other tools are inspiration only, taken from their documentation and behaviour, never their source, and described in our own words. Before each release a clone check against every public codebase named as a source of ideas finds no copied code outside the credited parts. |
