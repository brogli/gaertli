# Log and comparison

## Log viewer (LOG)

| ID        | Prio | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| --------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-LOG-01 | MUST | List the commits of all branches by default. Per commit: graph, subject, author, date, short hash, and ref labels (local branches, remote branches, tags, HEAD). Subject, author, date and short hash line up in columns on every row, whatever a row's ref labels or selection.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| FR-LOG-02 | MUST | Show a branch graph with merges and forks: every line connects a commit to its parents. While an author filter is active, the log shows a flat list without graph lines. A branch line keeps its colour until it reaches the tip of a local branch, where it takes a new one, so a branch's own commits stand apart from the branch it was started on: a feature branch made on main shows its commits in one colour and main's tip and below in another. Only local branches do this; remote branches and tags leave a line's colour as it is. A colour is never reused while its line runs. The colours come from a set that is readable in both themes and distinct from the diff's and the comparison's colours; when branch lines outnumber the set, it repeats. At most 32 branch lines show side by side; a row with more shows how many more as "+k". |
| FR-LOG-03 | MUST | Select a commit to see details: full message, author, committer, dates, parents, list of changed files.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| FR-LOG-04 | MUST | Open the diff of any changed file of a commit (vs its parent), in the diff window (FR-DIFF-07).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| FR-LOG-05 | MUST | Filter by author. Search by message text or hash: the search hides no commit. It highlights the matches among the commits the filters show, scrolls to the first, and shows which match of how many is current. Enter and Shift+Enter step to the next and previous match, wrapping around at both ends. Escape in the search field empties it. A commit the filters leave out is no match, also when searched by its hash.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| FR-LOG-06 | MUST | Filter by one or more branches or tags, found by searching their names; the list groups local branches, remote branches and tags. Filtering by a tag shows the history that leads to it. A tag in the branch picker also offers to show its history, which sets this filter to that tag, keeps the other filters, and brings the log view forward. Branches and tags are told apart by their full names, so a branch and a tag of the same name stay separate entries.                                                                                                                                                                                                                                                                                                                                                                                        |
| FR-LOG-07 | MUST | Filter by file or folder path.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| FR-LOG-08 | MUST | Filters combine: the log shows the commits that pass all of them. Each filter shows its value in its own field and can be emptied with one click.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| FR-LOG-09 | MUST | The log is usable before the full history is loaded. If loading fails, the log view says so (FR-UX-01).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| FR-LOG-10 | MUST | Mark which commits are checked out, and in which worktree.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| FR-LOG-11 | MUST | Act on the selected commits from the log view's context menu. It offers only what applies to the selection, worded for it. Right-clicking a commit outside the selection selects that commit alone first. For one commit: copy hash, copy subject, new branch from here, check out commit, reset current branch to here, cherry-pick and revert (each with its options, FR-CP-06, FR-RV-04), create worktree here, compare with working tree, and "Compare with <short hash>" naming the commit selected before. For two or more: cherry-pick, revert, squash and fixup (FR-LOG-14) of all of them, each labelled with their count, and copy their hashes; for exactly two, also swap (FR-CMP-03) and stop comparing.                                                                                                                                         |
| FR-LOG-13 | MUST | Ctrl-click adds a commit to the selection or takes it out; Shift-click selects every commit from the anchor, the commit last clicked plainly or with Ctrl, to the clicked one. A plain click selects that commit alone. A selection works the same however it was made: two selected commits form a comparison (FR-CMP-01); with three or more there is none, and the commit detail view says how many commits are selected. Dragging over the log selects no text; hash and subject are copied from the context menu (FR-LOG-11).                                                                                                                                                                                                                                                                                                                            |
| FR-LOG-14 | MUST | Squash turns two or more selected commits of the current branch into one, with their messages combined and shown for editing first; fixup does the same but keeps the oldest selected commit's message. The new commit's message is exactly the edited one (for fixup the oldest commit's), whatever the user's git config says about cleaning up messages; git hooks run as for any commit (FR-CHG-07). The new commit takes the oldest selected commit's place; the other commits keep their order.                                                                                                                                                                                                                                                                                                                                                         |
| FR-LOG-15 | MUST | The commit detail view shows a commit's message and fields and its changed files as two parts, each scrolling on its own. The user can resize the two parts; the split stays where the user last put it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| FR-LOG-16 | MUST | Every list of changed files (the commit detail view, the diff window, the change list) shows as a flat list of paths or as a folder tree, at the user's choice, which is one setting remembered for all of them. The tree starts with every folder unfolded and lists folders before files. A folder that holds nothing but one other folder is merged with it into one entry (`src/app`). A click or Enter on a folder folds or unfolds it. A file works the same in both: a click selects it, a double-click or Enter opens its diff, and it keeps its status icon (FR-UX-13) and Open in editor. Switch and fold button: FR-LOG-21.                                                                                                                                                                                                                        |
| FR-LOG-17 | MUST | Squash and fixup are not offered, and the menu says why, when a selected commit is not on the current branch, a merge commit is in the way, HEAD is detached, another operation is in progress, or tracked files have uncommitted changes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| FR-LOG-18 | MUST | Squash and fixup ask first, and say when a selected commit is already pushed, since the branch then needs a force push (FR-SYNC-05, FR-SYNC-06).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| FR-LOG-19 | MUST | If moving a commit next to another conflicts during a squash or fixup, the conflict flow takes over (FR-CONF); if the operation stops for another reason, the app shows git's reason and the operation can be continued or aborted the same way.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| FR-LOG-20 | MUST | After a squash or fixup, a notice names the branch's previous commit, copyable, so the user can go back.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| FR-LOG-21 | MUST | The list/tree switch's icon and label show what a click does: the tree icon while the list shows, the list icon while the tree shows. In tree mode, one fold button sits next to the switch: a click folds every folder, the next unfolds them all, its icon showing what a click does. It acts on every tree in its panel at once, in the change list on all its groups together. The folded-or-unfolded state is not remembered across windows, but holds while the files refresh. The scroll bar never covers the switch or the fold button.                                                                                                                                                                                                                                                                                                               |

## Compare commits (CMP)

| ID        | Prio | Requirement                                                                                                                                                                                                                                                                                                                                                                                                              |
| --------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| FR-CMP-01 | MUST | Compare two commits: select a second commit (FR-LOG-13), or choose "Compare with <short hash>" on a commit (FR-LOG-11). A comparison runs from the commit selected first to the one selected second, whatever their dates. The commit detail view shows the files that differ, with their status (FR-UX-13). "Stop comparing" (in the log view's menu or as the comparison's close button) or Escape (FR-UX-05) ends it. |
| FR-CMP-02 | MUST | Open the diff of any file in that list, in the diff window (FR-DIFF-07).                                                                                                                                                                                                                                                                                                                                                 |
| FR-CMP-03 | MUST | The commit detail view shows the comparison's direction (from → to) and offers Swap, which reverses it; the log view's marks swap with it (FR-CMP-05).                                                                                                                                                                                                                                                                   |
| FR-CMP-04 | MUST | Compare a commit with the working tree. Untracked files are not part of it, and the comparison says so. Its close button or Escape (FR-UX-05) ends it.                                                                                                                                                                                                                                                                   |
| FR-CMP-05 | MUST | The log view marks the two compared commits in two colours, one per side; neither is green or red, which diffs use for added and removed lines. A mark never moves the row's content. The commit detail view shows each side's short hash in that side's colour; the sides are not labelled older and newer.                                                                                                             |
