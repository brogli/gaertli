# Log and comparison

## Log viewer (LOG)

| ID        | Prio   | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-LOG-01 | MUST   | List the commits of all branches by default. Per commit: graph, subject, author, date, short hash, and ref labels (local branches, remote branches, tags, HEAD). Subject, author, date and short hash line up in columns on every row in view, whatever a row's ref labels or selection.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| FR-LOG-02 | MUST   | Show a branch graph with merges and forks. Every line connects a commit to its parents: a merge's lines run from the merge commit to the line of each branch it merged, and a fork's lines run from each branch into the commit they share. While an author filter is active, a flat list without graph lines is acceptable. Each branch line keeps its own colour for as long as it runs; the colours come from a set that repeats when branch lines outnumber it, readable in both themes and distinct from the diff's and the comparison's colours. At most 32 branch lines show side by side; a row with more shows how many more as "+k".                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| FR-LOG-03 | MUST   | Select a commit to see details: full message, author, committer, dates, parents, list of changed files.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| FR-LOG-04 | MUST   | Open the diff of any changed file of a commit (vs its parent), in the diff window (FR-DIFF-07).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| FR-LOG-15 | MUST   | The commit detail view shows a commit's message and fields and its changed files as two parts, each scrolling on its own. The user can resize the two parts; the split stays where the user last put it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| FR-LOG-16 | MUST   | The changed files of a commit or a comparison, here and in the diff window (FR-DIFF-10), show as a flat list of paths or as a folder tree, at the user's choice, which is remembered. The tree starts with every folder unfolded, lists folders before files, and shows a folder that holds only one folder and no files together with it as one entry (`src/app`). A click or Enter on a folder folds or unfolds it. A file works the same in both: a click selects it, a double-click or Enter opens its diff, and it keeps its status icon (FR-UX-13) and Open in editor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| FR-LOG-05 | MUST   | Filter by author. Search by message text or hash: the search hides no commit; it highlights the matching commits among those the filters show, scrolls to the first, steps to the next or previous match (Enter, Shift+Enter), from the last match on to the first and from the first back to the last, and shows which match of how many is current. Escape in the search field empties it. A commit the filters leave out is no match, also when searched by its hash.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| FR-LOG-06 | MUST   | Filter by one or more branches or tags, found by searching their names; the list groups local branches, remote branches and tags. Filtering by a tag shows the history that leads to it. A tag in the branch picker also offers to show its history, which sets this filter to that tag, keeps the other filters, and brings the log view forward.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| FR-LOG-07 | MUST   | Filter by file or folder path.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| FR-LOG-08 | MUST   | Filters can be combined: the log shows the commits that pass all of them. Each filter shows its value in its own field and can be emptied with one click. No separate list of active filters, no clear-all action.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| FR-LOG-09 | MUST   | The log is usable before the full history is loaded. If loading fails, the log view says so (FR-UX-01).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| FR-LOG-10 | MUST   | Mark which commits are checked out, and in which worktree.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| FR-LOG-11 | MUST   | Act on the selected commits from the log view's context menu. It offers only what applies to the selection it opens on, worded for it. Right-clicking a commit outside the selection selects that commit alone first. For one commit: copy hash, copy subject, new branch from here, check out commit, reset current branch to here, cherry-pick, revert (each also with its options, FR-CP-06, FR-RV-04), create worktree here, compare with working tree, and "Compare with <short hash>" naming the commit selected before. For two or more: cherry-pick and revert of all of them, squash and fixup (FR-LOG-14), each labelled with their count, and copy their hashes; for exactly two, also swap (FR-CMP-03) and stop comparing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| FR-LOG-12 | SHOULD | The log view's text cannot be selected: dragging over it selects nothing. Hash and subject are copied from the context menu (FR-LOG-11).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| FR-LOG-13 | MUST   | Ctrl-click adds a commit to the selection or takes it out; Shift-click selects every commit from the one clicked before to the clicked one. A selection works the same however it was made: two selected commits form a comparison (FR-CMP-01); with three or more there is none, and the commit detail view says how many commits are selected.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| FR-LOG-14 | MUST   | Squash turns two or more selected commits of the current branch into one, with their messages combined and shown for editing first; fixup does the same but keeps the oldest selected commit's message. The new commit's message is exactly the edited one, or for fixup the oldest commit's, whatever the user's git config says about cleaning up messages; git hooks run as for any commit (FR-CHG-07). The new commit takes the oldest selected commit's place; the other commits keep their order. Both ask first, and say when a selected commit is already pushed, since the branch then needs a force push (FR-SYNC-05), with the extra warning on a protected branch (FR-SYNC-06). They are not offered, and the menu says why, when a selected commit is not on the current branch, a merge commit is in the way, HEAD is detached, another operation is in progress, or tracked files have uncommitted changes (untracked files do not count). If moving a commit next to another conflicts, the operation stops and the conflict flow takes over (FR-CONF); if it stops for another reason, it shows git's reason and can be continued or aborted the same way. Afterwards a notice names the branch's previous commit, copyable, so the user can go back. |

## Compare commits (CMP)

| ID        | Prio | Requirement                                                                                                                                                                                                                                                                                                                                                                                                              |
| --------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| FR-CMP-01 | MUST | Compare two commits: select a second commit (FR-LOG-13), or choose "Compare with <short hash>" on a commit (FR-LOG-11). A comparison runs from the commit selected first to the one selected second, whatever their dates. The commit detail view shows the files that differ, with their status (FR-UX-13). "Stop comparing", in the log view's menu or as the comparison's close button, or Escape (FR-UX-05) ends it. |
| FR-CMP-02 | MUST | Open the diff of any file in that list, in the diff window (FR-DIFF-07).                                                                                                                                                                                                                                                                                                                                                 |
| FR-CMP-03 | MUST | The commit detail view shows the comparison's direction (from → to) and offers Swap, which reverses it; the log view's marks swap with it (FR-CMP-05).                                                                                                                                                                                                                                                                   |
| FR-CMP-04 | MUST | Compare a commit with the current working files. Untracked files are not part of it, and the comparison says so. Its close button or Escape (FR-UX-05) ends it.                                                                                                                                                                                                                                                          |
| FR-CMP-05 | MUST | The log view marks the two compared commits in two colours, one for the from side and one for the to side; neither is green or red, which diffs use for added and removed lines. A mark never moves the row's content. The commit detail view shows each side's short hash in that side's colour, matching its mark; the sides are not labelled older and newer.                                                         |
