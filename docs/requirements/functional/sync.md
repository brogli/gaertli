# Fetch, pull, push

| ID         | Prio | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-SYNC-01 | MUST | Fetch from one remote or all remotes. Remove remote branches that no longer exist.                                                                                                                                                                                                                                                                                                                                                                                     |
| FR-SYNC-02 | MUST | Pull the current branch with merge or rebase. The Pull button names its mode ("Pull (merge)", "Pull (rebase)") and pulls on a click or its shortcut. The menu beside it only chooses the mode; choosing never pulls. The chosen mode is the default pull mode in Settings (FR-UX-04), so every window and the next start pull the same way.                                                                                                                            |
| FR-SYNC-03 | MUST | Push the current branch, also one that has no upstream yet (FR-SYNC-12). The Push button reads "Push" and its shortcut works with or without an upstream.                                                                                                                                                                                                                                                                                                              |
| FR-SYNC-04 | MUST | If a push is rejected, explain why and offer: pull, or force push.                                                                                                                                                                                                                                                                                                                                                                                                     |
| FR-SYNC-05 | MUST | Force push only in the safe form: it fails if the remote has commits the user has not fetched. Plain force push is not offered.                                                                                                                                                                                                                                                                                                                                        |
| FR-SYNC-06 | MUST | Force push asks for confirmation. Protected branches (configurable, default `main`, `master`) get an extra warning. Settings take them one name at a time, suggesting the current repo's matching branch names; each entry can be removed.                                                                                                                                                                                                                             |
| FR-SYNC-07 | MUST | Remote actions show progress and can be cancelled, in the jobs menu (FR-UX-12). Cancelling leaves the repo as git leaves it when interrupted: no lock file of git's blocks the next action, and an operation stopped mid-way can be continued or aborted.                                                                                                                                                                                                              |
| FR-SYNC-08 | MUST | Use the user's existing git login; the app never asks for or sees credentials. If login fails, say so and show git's message.                                                                                                                                                                                                                                                                                                                                          |
| FR-SYNC-09 | MUST | If a pull, merge or rebase is blocked by local changes, offer, on the failure notice, to stash them, run it, and restore them after. If they cannot be restored cleanly, the stash waits: once no file is conflicted the app offers to restore it or drop it; dropping asks first (FR-UX-03).                                                                                                                                                                          |
| FR-SYNC-10 | MUST | Automatic fetch at a set interval. Off by default.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| FR-SYNC-11 | MUST | Sync controls offer only what can act. Without a remote, Fetch, Pull and Push are disabled and their tooltip says the repo has no remote. A choice of remote appears only when there is more than one. No control shows an empty list.                                                                                                                                                                                                                                 |
| FR-SYNC-12 | MUST | A branch without an upstream gets one on its first push, as git's `push.autoSetupRemote` says: when it is true, Push creates the branch of the same name on the push remote, sets it as the upstream and pushes without asking; otherwise Push first asks in a dialog that names the branch and the remote. The push remote is the one git itself would pick; when git has none, Push asks which, and with more than one remote the dialog lets the user pick another. |
| FR-SYNC-13 | MUST | If the remote already has a branch of the pushed branch's name, a first push (FR-SYNC-12) only fast-forwards it: a rejected first push sets no upstream, and its notice explains the rejection (FR-SYNC-04) without offering pull or force push, which need an upstream.                                                                                                                                                                                               |
