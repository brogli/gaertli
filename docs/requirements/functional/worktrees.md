# Worktrees

| ID       | Prio   | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-WT-01 | MUST   | List all worktrees. Per worktree: path, branch or detached commit, clean/dirty, flags (main, locked, missing). A bare repo's own entry is listed by its folder and marked bare; it has no files to work in, so it cannot be chosen and offers no actions.                                                                                                                                                                                                                                                                                                                                                                                       |
| FR-WT-02 | MUST   | Create a worktree on an existing branch, or on a new branch started from a branch or tag, each picked from a searchable list that starts at the current branch. Created from the log view (FR-LOG-11), the new branch starts at that commit; from a tag's menu, at that tag. A new branch started from a remote branch does not track it (FR-BR-14). The only things typed are the folder name (FR-WT-18), a new branch's name and, if wanted, a different location.                                                                                                                                                                            |
| FR-WT-03 | MUST   | The target folder must not exist or must be empty. Otherwise reject with a clear message.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| FR-WT-04 | MUST   | A worktree opens in the external editor (FR-ED-01) with one action on its entry in the worktree picker (FR-WT-17).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| FR-WT-05 | MUST   | A window acts on one selected worktree. The repo and worktree pickers (FR-WT-13) pick it; the whole window (log view, branch picker, changes view, diff window) follows it, and changes, commit, pull, push, reset, checkout, cherry-pick and revert act on that worktree only.                                                                                                                                                                                                                                                                                                                                                                 |
| FR-WT-07 | MUST   | Remove a worktree. Confirm first. Refuse if it has uncommitted changes unless the user forces it. Clean up stale entries.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| FR-WT-08 | MUST   | Choosing a worktree in the worktree picker switches this window to it. "Open in new window" shows it in a second window; if a window already shows it, that one is focused instead.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| FR-WT-09 | MUST   | The window title shows the selected worktree's folder name and current branch, so windows are easy to tell apart; a window with no worktree shows the app's name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| FR-WT-10 | MUST   | Log, branches, tags, and the worktree list are the same in all windows of one repo and stay in sync.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| FR-WT-11 | MUST   | Windows on worktrees of different repos can be open at the same time.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| FR-WT-12 | SHOULD | After creating a worktree, offer: open in app window, open in editor, both.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| FR-WT-13 | MUST   | The user switches repo, worktree and branch with three toolbar pickers: the repo picker, the worktree picker and the branch picker (FR-BR-09). Each names the current choice and opens a searchable list: typing filters it, the arrow keys move through it and Enter chooses.                                                                                                                                                                                                                                                                                                                                                                  |
| FR-WT-14 | MUST   | A folder is the same worktree however its path is written (either kind of slash, Windows' short form, through a link): the app finds the worktree git lists for that folder. Worktree paths are shown the way git lists them.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| FR-WT-15 | MUST   | A picker entry's actions are in its menu, opened by a right-click, the context-menu key, Shift+F10 or the "…" button at the row's end; the most used ones are also buttons on the row. A button acts on its entry without choosing it. Choosing an action closes the list; a refusal then shows as a notice.                                                                                                                                                                                                                                                                                                                                    |
| FR-WT-16 | MUST   | The repo picker lists the recent repos (FR-REPO-08); choosing one switches this window to that repo's last shown worktree, else to its main worktree, also when the last shown one no longer exists. A repo is named by its main worktree. Listing the recent repos starts nothing: a WSL repo's environment starts only when the user chooses it. It also offers "Open folder…" (FR-REPO-01, FR-REPO-07), which switches this window to the picked repo or brings forward the window that already shows it, and "New window" (Ctrl+Shift+N), which opens a window with no worktree; such a window shows the repo picker's list as its content. |
| FR-WT-17 | MUST   | The worktree picker lists the current repo's worktrees (FR-WT-01), each named by its folder and branch, with buttons to open it in a new window (FR-WT-08), open it in the editor (FR-WT-04) or remove it (FR-WT-07); its menu adds "Switch to worktree" for any worktree but the current one. It also offers "New worktree…" (FR-WT-02).                                                                                                                                                                                                                                                                                                       |
| FR-WT-18 | MUST   | The user names the new worktree's folder; its location is the base folder for worktrees (FR-UX-04) plus that name, and the name and the location's last folder stay in step. The name starts as the repo's folder name and the branch name joined by a hyphen (a slash in the branch becomes a hyphen) and follows the branch until the user edits the name or the location.                                                                                                                                                                                                                                                                    |
