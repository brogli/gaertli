| FR-WT-01 | MUST   | List all worktrees. Per worktree: path, branch or detached commit, clean/dirty, flags (main, locked, missing). A bare repo's own entry is listed by its folder and marked bare; it has no files to work in, so it cannot be chosen and offers no actions.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| FR-WT-02 | MUST   | Create a worktree on an existing branch, or on a new branch starting from an existing branch or tag, each picked from a searchable list; the start list starts at the current branch. Created from the log view (FR-LOG-11), the new branch starts at that commit; from a tag's menu, at that tag. A new branch started from a remote branch does not track it, as with "New branch…" (FR-BR-01). The user names the worktree's folder; its location is the base folder for worktrees (FR-UX-04) plus that name, and the name and the location's last folder stay in step: changing one changes the other. The name starts as the repo's folder name and the branch name joined by a hyphen (a slash in the branch becomes a hyphen), and follows the branch until the name or the location is changed. The only things typed are the name, a new branch's name and, if wanted, a different location.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| FR-WT-03 | MUST   | The target folder must not exist or must be empty. Otherwise reject with a clear message.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| FR-WT-04 | MUST   | A worktree opens in the external editor (FR-ED-01) with one action on its entry in the worktree picker (FR-WT-13).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| FR-WT-05 | MUST   | **A window acts on one selected worktree.** The repo and worktree pickers (FR-WT-13) pick it; the whole window (log view, branch picker, changes view, diff window) follows it, and changes, commit, pull, push, reset, checkout, cherry-pick and revert act on that worktree only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

| FR-WT-09 | MUST   | The window title shows the selected worktree's folder name and current branch, so windows are easy to tell apart; a window with no worktree shows the app's name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| FR-WT-10 | MUST   | Log, branches, tags, and the worktree list are the same in all windows of one repo and stay in sync.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

| FR-WT-13 | MUST   | The user switches repo, worktree and branch with three pickers in the toolbar: the repo picker, the worktree picker and the branch picker (FR-BR-09). Each names the current choice and opens a searchable list: typing filters it, the arrow keys move through it and Enter chooses. An entry with actions has a menu holding all of them, opened by a right-click on the entry or by the context-menu key or Shift+F10 on the active one; actions its row does not show as buttons are also reached through a "…" button at the row's right end. A button on a row acts on its entry without choosing it. The repo picker lists the recent repos; choosing one switches this window to the worktree it last showed of that repo, else to the repo's main worktree. It also offers "Open folder…" (FR-REPO-01, FR-REPO-07), which switches this window to the picked repo or brings forward the window that already shows it, and "New window" (also Ctrl+Shift+N), which opens a window with no worktree. A window with no worktree shows the repo picker's list as its content. The worktree picker lists the current repo's worktrees (FR-WT-01, FR-WT-08), each named by its folder and its branch, with always visible buttons that open it in a new window (FR-WT-08), open it in the editor (FR-WT-04) or remove it (FR-WT-07); its menu holds the same actions and, for any worktree but the current one, "Switch to worktree". Choosing one of these actions, from its button or the menu, closes the list; a refusal then shows as a notice. The worktree picker also offers "New worktree…" (FR-WT-02). |
