# Repository

| ID         | Prio | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| FR-REPO-01 | MUST | Open a local repo by picking a folder. Any folder inside a repo or inside one of its worktrees works.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| FR-REPO-02 | MUST | Remember recent repos. Started without a path: reopen the windows that were open at last quit, each on its last selected worktree. Started with a path (FR-REPO-06): open that one only.                                                                                                                                                                                                                                                                                                                                 |
| FR-REPO-03 | MUST | Always show: repo, window's worktree, current branch, ahead/behind counts vs upstream, any operation in progress (merge, rebase, cherry-pick, revert), and detached HEAD. An operation in progress and a pull's waiting stash show as banners under the toolbar, not as notices.                                                                                                                                                                                                                                         |
| FR-REPO-04 | MUST | Pick up changes made outside the app (terminal, editor) while the window has focus: git-state changes (commit, checkout, staging, new branch) within 2 seconds, edits to working files within 3 seconds. Very large working trees may take longer; the app then shows that it is refreshing. The window also refreshes when it gains focus, and on demand.                                                                                                                                                               |
| FR-REPO-05 | MUST | If the folder is not a git repo, say so clearly. Do nothing else.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| FR-REPO-06 | MUST | Start from a terminal: `gaertli [path]` (`.` for the current folder) opens or focuses the window for that worktree and returns at once; without a path the app starts as FR-REPO-02 says. From a WSL terminal the same command opens the app on Windows, showing the WSL repo, with nothing installed inside the distro by hand (QA-PORT-02).                                                                                                                                                                            |
| FR-REPO-07 | MUST | On Windows, "Open folder…" opens a repo on the Windows file system or inside a WSL distro from the same folder dialog; the app tells the two apart by itself, and both behave the same afterwards. Recent repos show which kind each is. A repo in a WSL distro that is not installed says so.                                                                                                                                                                                                                           |
| FR-REPO-08 | MUST | In the repo picker (FR-WT-16), every recent repo but the window's own has a menu with "Open in new window" and "Remove from recents". Open in new window opens the repo in a window of its own, at that repo's last shown worktree, else at its main worktree (also when that worktree no longer exists); if a window already shows that worktree, it is brought forward instead. Remove from recents only takes the repo off the list: its folders and any window showing it stay, and opening it again lists it again. |
