# Diff

| ID         | Prio   | Requirement                                                                                                                                                                                                                                                                                                                         |
| ---------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-DIFF-01 | MUST   | Show git's own diff, side by side or unified: the user's git config (diff algorithm, attributes, filters, line endings) decides which lines changed, and changed lines are marked whole. The user switches between the two; the choice is remembered. The diff's toolbar stays in view while the diff scrolls.                      |
| FR-DIFF-02 | MUST   | Jump to next/previous change and next/previous file.                                                                                                                                                                                                                                                                                |
| FR-DIFF-19 | MUST   | The change the cursor is in is the selected change, whichever side of a side-by-side diff was clicked; clicking an unchanged line selects none. It is outlined and marked in the gutter as the merge editor does (FR-CONF-17), in a side-by-side diff on both sides. Next and previous step from it.                                |
| FR-DIFF-20 | MUST   | A file's diff opens with its first change selected and in view. A reload, or a switch between unified and side by side, keeps the selection where the cursor was.                                                                                                                                                                   |
| FR-DIFF-21 | MUST   | Stepping to a change or to a search match brings it to the vertical middle of its pane, as stepping does in the merge editor.                                                                                                                                                                                                       |
| FR-DIFF-03 | MUST   | Binary files are shown as "binary", without content.                                                                                                                                                                                                                                                                                |
| FR-DIFF-04 | MUST   | Very large files do not freeze the app. Warn and load on demand.                                                                                                                                                                                                                                                                    |
| FR-DIFF-05 | SHOULD | Syntax highlighting.                                                                                                                                                                                                                                                                                                                |
| FR-DIFF-06 | MUST   | Ignore whitespace on demand: the diff is then git's whitespace-ignoring diff, for reading only. The control names the diff's state: "Showing whitespace" or "Ignoring whitespace". Hunk and line actions are offered only with whitespace shown; the view says so.                                                                  |
| FR-DIFF-07 | MUST   | Diffs are read in a window of their own, the diff window: every file diff opens there by double-clicking the file or pressing Enter on it, and the main window shows no diff. One diff window per main window; opening another diff reuses it. Escape or its close button closes it; the main window stays usable while it is open. |
| FR-DIFF-13 | MUST   | The diff window lists the changed files of what it shows (a commit, a comparison or the working tree) and shows the chosen file's diff. For a working-tree file it offers hunk and line staging and discard (FR-CHG-03, FR-CHG-10).                                                                                                 |
| FR-DIFF-08 | MUST   | In the side-by-side diff, the two sides scroll together: scrolling either side up, down or sideways moves the other with it. Each side's scrollbars and the divider between the sides stay in view, and a window too short for the diff still shows the sides at a readable height.                                                 |
| FR-DIFF-09 | MUST   | The user sizes the diff window's file list and each side of a side-by-side diff; the window keeps that layout, also after it is closed and opened again.                                                                                                                                                                            |
| FR-DIFF-10 | MUST   | The diff window's file list follows the flat or tree choice of FR-LOG-16. A working tree's files keep their groups (staged, unstaged, untracked, conflicted), each shown the chosen way.                                                                                                                                            |
| FR-DIFF-11 | MUST   | In every theme the user tells added, removed and unchanged lines apart at a glance, and reads changed lines as easily as the rest.                                                                                                                                                                                                  |
| FR-DIFF-12 | MUST   | The diff window opens at the size the user last left it at; a maximised window does not change that size. Where it opens on the screen is up to the system.                                                                                                                                                                         |
| FR-DIFF-14 | MUST   | Ctrl+F in the diff window opens a search bar at the top of the diff it searches. Every match is highlighted; Enter and Shift+Enter step to the next and previous match, wrapping around at both ends. Escape closes the search and leaves the diff window open.                                                                     |
| FR-DIFF-15 | MUST   | In the side-by-side diff each side has its own search, which covers that side only. Ctrl+F opens the search of the side the cursor is in, otherwise the right side's.                                                                                                                                                               |
| FR-DIFF-16 | MUST   | In the unified diff the search covers the file's current lines, unchanged and added. Removed lines are not searched; the left side of the side-by-side diff finds them.                                                                                                                                                             |
| FR-DIFF-17 | SHOULD | The search can match case, whole words or a regular expression.                                                                                                                                                                                                                                                                     |
| FR-DIFF-22 | MUST   | The diff's toolbar opens the search too: one button in the unified diff, one for each side in the side-by-side diff. The unified diff's button and the right side's show the Ctrl+F shortcut (FR-UX-05).                                                                                                                            |
| FR-DIFF-23 | MUST   | An open search stays open, with its text, when the diff reloads or another file is shown.                                                                                                                                                                                                                                           |
| FR-DIFF-18 | MUST   | The diff shows line numbers beside its lines. In the side-by-side diff each side numbers its own version of the file. In the unified diff the file's current lines are numbered and removed lines have no number.                                                                                                                   |
| FR-DIFF-24 | MUST   | Right-clicking a line number offers "Copy path:line", which copies the file's path in the repo and that line's number, e.g. `src/app.go:42`. For a renamed file the left side of a side-by-side diff copies the old path.                                                                                                           |
