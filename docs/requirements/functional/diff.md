# Diff

| ID         | Prio   | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-DIFF-01 | MUST   | Show git's own diff, side by side or unified: the user's git config (diff algorithm, attributes, filters, line endings) decides which lines changed, and changed lines are marked whole. The user switches between the two; the choice is remembered.                                                                                                                                                                                                                                                                                                                   |
| FR-DIFF-02 | MUST   | Jump to next/previous change and next/previous file.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| FR-DIFF-03 | MUST   | Binary files are shown as "binary", without content.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| FR-DIFF-04 | MUST   | Very large files do not freeze the app. Warn and load on demand.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| FR-DIFF-05 | SHOULD | Syntax highlighting.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| FR-DIFF-06 | SHOULD | Ignore whitespace on demand: the diff is then git's whitespace-ignoring diff, for reading only. The control names the diff's state: "Showing whitespace" or "Ignoring whitespace". Hunk and line actions are offered only with whitespace shown; the view says so.                                                                                                                                                                                                                                                                                                      |
| FR-DIFF-07 | MUST   | Diffs are read in a window of their own, the diff window: every file diff opens there by double-clicking the file or pressing Enter on it, and the main window shows no diff. The diff window lists the changed files of what it shows (a commit, a comparison or the working tree) and shows the chosen file's diff; for a working-tree file it offers hunk and line staging and discard (FR-CHG-03, FR-CHG-10). One diff window per main window; opening another diff reuses it. Escape or its close button closes it; the main window stays usable while it is open. |
| FR-DIFF-08 | SHOULD | In the side-by-side diff the two sides scroll sideways together, as they scroll up and down together: scrolling either side sideways moves the other with it, as far as its lines reach.                                                                                                                                                                                                                                                                                                                                                                                |
| FR-DIFF-09 | SHOULD | The user sizes the diff window's parts: a splitter between the file list and the diff, and in the side-by-side diff one between the two sides. Each splitter stays where the user last put it, also when the diff window is closed and opened again.                                                                                                                                                                                                                                                                                                                    |
| FR-DIFF-10 | SHOULD | The diff window's files show as a flat list or a folder tree with the same toggle above them and the same remembered choice as the commit detail view's changed files (FR-LOG-16). A working tree's files keep their groups (staged, unstaged, untracked, conflicted), each shown the chosen way.                                                                                                                                                                                                                                                                       |
| FR-DIFF-11 | SHOULD | In every theme, added and removed lines stand out clearly from unchanged lines and from each other, and stay as readable as the rest: an added or removed line's background differs from the diff's background, and the two from each other, by a colour difference (ΔE in OKLab) of at least 0.08; the text on them keeps a contrast ratio of at least 4.5:1; the change marker beside a changed line has at least 3:1 against the diff's background.                                                                                                                  |
| FR-DIFF-12 | SHOULD | In the desktop app the diff window opens at the size it had when the user last closed it; a window closed while maximised leaves that size as it was. Where it opens on the screen is not remembered.                                                                                                                                                                                                                                                                                                                                                                   |
