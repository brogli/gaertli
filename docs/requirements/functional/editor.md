# External editor

The app is editor-neutral.

| ID       | Prio   | Requirement                                                                                                                                                                                                                                                                                                                               |
| -------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-ED-01 | MUST   | Open a worktree folder in the external editor.                                                                                                                                                                                                                                                                                            |
| FR-ED-02 | MUST   | Open a file in the external editor from every file list: the change list (conflicted files included), the commit detail view and the diff window.                                                                                                                                                                                         |
| FR-ED-11 | MUST   | The editor is set per environment, because the command runs where the repo lives: the local system and each installed WSL distro always have their own editor setting, named after the environment, and a repo uses its own environment's.                                                                                                |
| FR-ED-03 | MUST   | The user configures which editor is used; every "open in editor" action uses the setting of the repo's environment (FR-ED-11). Settings label it as the setting behind "Open in …".                                                                                                                                                       |
| FR-ED-04 | MUST   | The user can enter any custom command, with separate forms for opening a folder, a file, and a file at a line (the file form is used when the line form is empty).                                                                                                                                                                        |
| FR-ED-12 | MUST   | A custom editor command is written as on the command line of the system it runs on: spaces separate words and double quotes keep a word with spaces together. On Windows a backslash or a single quote is an ordinary character, as in a folder path; elsewhere single quotes group too and a backslash makes the next character literal. |
| FR-ED-13 | MUST   | A file opened in the editor shows its content whichever window the editor last used, also when that window belongs to another environment than the file (FR-ED-11). The default editor setting and the presets (FR-ED-07) provide for this.                                                                                               |
| FR-ED-05 | MUST   | Default is the editor. The UI says "Open in editor", or shows the configured editor's name, never a fixed "Open in the editor". A saved change shows at once in every window.                                                                                                                                                                           |
| FR-ED-06 | MUST   | If the editor cannot be started, a notice says so and names the command that failed, and nothing more.                                                                                                                                                                                                                                    |
| FR-ED-07 | SHOULD | Presets for common editors (e.g. the editor, another editor, an IDE, a third editor, a terminal editor in a terminal) so the user only picks from a list.                                                                                                                                                                                                     |
| FR-ED-09 | SHOULD | Open the file at the line shown in the diff, if the editor command supports it.                                                                                                                                                                                                                                                           |
