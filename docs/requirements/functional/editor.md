# External editor

The app is editor-neutral.

| ID       | Prio   | Requirement                                                                                                                                                                                                                                                                                                                               |
| -------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-ED-01 | MUST   | Open a worktree folder in the external editor.                                                                                                                                                                                                                                                                                            |
| FR-ED-02 | MUST   | Open a file in the external editor from every file list: the change list (conflicted files included), the commit detail view and the diff window.                                                                                                                                                                                         |
| FR-ED-03 | MUST   | The user configures which editor is used. Settings label it as the setting behind "Open in …".                                                                                                                                                                                                                                            |
| FR-ED-11 | MUST   | One editor setting serves every repo. For a repo in a WSL distro its command runs inside that distro, so editors with WSL support (VS Code, Zed) open it in their remote WSL window.                                                                                                                                                      |
| FR-ED-04 | MUST   | The user can enter any custom command, with separate forms for opening a folder, a file, and a file at a line (the file form is used when the line form is empty).                                                                                                                                                                        |
| FR-ED-12 | MUST   | A custom editor command is written as on the command line of the system it runs on: spaces separate words and double quotes keep a word with spaces together. On Windows a backslash or a single quote is an ordinary character, as in a folder path; elsewhere single quotes group too and a backslash makes the next character literal. |
| FR-ED-05 | MUST   | No editor is configured by default. The UI says "Open in editor" until one is named, then "Open in <name>". A saved change shows at once in every window.                                                                                                                                                                                 |
| FR-ED-13 | MUST   | A file opens in the editor window the user last used, also when that window shows a repo of another environment (Windows or a WSL distro) than the file's. The presets (FR-ED-07) are written so this works.                                                                                                                              |
| FR-ED-06 | MUST   | If the editor cannot be started, a notice says so and names the command that failed, or says that no editor is configured, and nothing more.                                                                                                                                                                                              |
| FR-ED-07 | SHOULD | Presets for common editors, so the user only picks from a list.                                                                                                                                                                                                                                                                           |
| FR-ED-09 | SHOULD | Open the file at the line shown in the diff, if the editor command supports it.                                                                                                                                                                                                                                                           |
