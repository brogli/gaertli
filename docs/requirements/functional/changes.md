# Changes, commit and conflicts

## Changes and commit (CHG)

| ID        | Prio   | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-CHG-01 | MUST   | Show changed files of this window's worktree in groups: staged, unstaged, untracked, conflicted.                                                                                                                                                                                                                                                                                                                                                                                                     |
| FR-CHG-02 | MUST   | Stage and unstage whole files, and all files at once.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| FR-CHG-03 | MUST   | Stage and unstage single hunks and selected lines in the diff (whitespace shown, FR-DIFF-06). A hunk is git's hunk as the diff shows it; a file's mode change belongs to no hunk. Where a hunk replaces lines one for one, a selected line moves as a whole change, its removed and its added version together; where it replaces them with a different number of lines, a line selection takes the whole hunk. An action refuses, changing nothing, when the file changed since the diff was shown. |
| FR-CHG-04 | MUST   | Show the diff of any changed file, in the diff window (FR-DIFF-07).                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| FR-CHG-05 | MUST   | Commit staged changes with a message. Blocked when nothing is staged or the message is empty or only spaces. The Commit button names how many files are staged: "Commit (3)".                                                                                                                                                                                                                                                                                                                        |
| FR-CHG-06 | MUST   | Amend the last commit: ticking "Amend last commit" fills the message field with that commit's message, unless the field already holds text; the Commit button then reads "Amend" and needs nothing staged. Not offered before the first commit or while an operation (merge, rebase, …) is in progress. Warn if that commit is already pushed.                                                                                                                                                       |
| FR-CHG-07 | MUST   | Git hooks run as usual. If a hook fails, show its output.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| FR-CHG-08 | MUST   | Keep the message draft until the commit succeeds.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| FR-CHG-09 | SHOULD | Commit and push in one action: with "Push after commit" ticked, a successful commit is pushed the way Push pushes it (FR-SYNC-03). On a branch without an upstream, the branch gets one the same way, with or without asking. The option is unavailable while amending, on a detached HEAD and in a repo without a remote.                                                                                                                                                                           |
| FR-CHG-11 | MUST   | Committing never needs scrolling: the commit box stays in view however long the change list (FR-CHG-01) is.                                                                                                                                                                                                                                                                                                                                                                                          |
| FR-CHG-12 | MUST   | The commit message field shows at least six lines without scrolling.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| FR-CHG-10 | SHOULD | Discard changes per file, hunk or selected lines, with confirmation. Line selections and refusals work as for staging (FR-CHG-03), so a discarded line gets its previous version back: a discard never removes a line the file had before without restoring it.                                                                                                                                                                                                                                      |

## Conflicts (CONF)

| ID         | Prio | Requirement                                                                                                 |
| ---------- | ---- | ----------------------------------------------------------------------------------------------------------- |
| FR-CONF-01 | MUST | Detect when a pull, merge, rebase, cherry-pick, or revert stopped on conflicts. List the conflicted files.  |
| FR-CONF-02 | MUST | Open a conflicted file in the editor. Conflicts are resolved there; the app has no merge editor of its own. |
| FR-CONF-03 | MUST | Mark a file as resolved.                                                                                    |
| FR-CONF-04 | MUST | Continue or abort the running operation.                                                                    |
