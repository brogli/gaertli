# Branches

## Branch actions (BR)

| ID       | Prio | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-BR-01 | MUST | Create a branch from any commit (FR-LOG-11), or from a branch or tag picked from a searchable list that groups local branches, remote branches and tags. The list starts at the current branch, or at the branch or tag whose actions opened it; while HEAD is detached, "New branch…" starts the branch at HEAD. A branch and a tag of the same name each work as a start. Only the new branch's name is typed; an option checks it out after creation. A branch started from a remote branch does not track it, whatever its name: its first push gives it an upstream of its own name (FR-SYNC-03). A local branch that tracks a remote branch comes from checking the remote branch out (FR-BR-09). Invalid or duplicate names are rejected with a clear message.                                                                                                                                                                                                                                                                                   |
| FR-BR-02 | MUST | Reset the current branch to a commit ("Reset current branch to here…", FR-LOG-11) in a mode the user picks each time, seeing the branch, the target commit (short hash and subject) and each mode explained in one short plain line: soft (the undone commits' changes stay staged), mixed (they stay in the files, unstaged; preselected, as in git), hard (they are discarded, and so are all uncommitted changes), keep (FR-BR-07).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| FR-BR-03 | MUST | Hard reset asks for confirmation and shows what will be lost (number of uncommitted changed files).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| FR-BR-04 | MUST | After a successful reset the log view shows the branch at its new commit at once, and a notice names the previous commit, copyable, so the user can go back. No further prompt follows.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| FR-BR-05 | MUST | Check out a local branch in this window's worktree. A branch checked out in another worktree, or being rebased or bisected there, is not checked out: the app says so and why, names that worktree and offers to switch this window to it, or to cancel. If git refuses (e.g. local changes in the way), show why.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| FR-BR-08 | MUST | Check out a commit from the log (detached HEAD), after a warning that commits made in this state belong to no branch. While detached, offer "create branch here".                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| FR-BR-07 | MUST | A fourth reset mode, keep: like hard, but uncommitted changes stay; it refuses if they touch a file the reset would change.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| FR-BR-06 | MUST | Rename and delete local branches. Deleting an unmerged branch needs confirmation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| FR-BR-09 | MUST | The branch picker (FR-WT-13) is where the user checks out and acts on branches and tags. It offers "New branch…", the local branches with ahead/behind, the remote branches and the tags. Clicking an entry checks it out (a local branch checked out in another worktree: FR-BR-05). Its menu (FR-WT-13), also opened by the "…" button at the right end of its row, holds its actions: check out (a local branch, FR-BR-05; a remote branch as a new tracking branch, or as the local branch of its name if there is one, also when a tag has that name; a tag as a detached HEAD, FR-BR-08), new branch from it (FR-BR-01), new worktree from it (FR-WT-02), update from upstream (FR-UPD-01), rename and delete (FR-BR-06, FR-BR-10), merge into the current branch and rebase the current branch onto it (FR-BR-11, FR-BR-12), show in log, and for a tag show its history (FR-LOG-06). Choosing an action closes the list; a refusal then shows as a notice. Several local branches can be selected in the list and updated together (FR-UPD-06). |
| FR-BR-10 | MUST | Deleting a local branch that another worktree has checked out, and renaming or deleting one that a worktree is rebasing or bisecting, is refused before anything runs: the app says so, names that worktree and says what to do there: check out another branch, or finish the rebase or bisect first. Renaming a branch checked out in another worktree renames it there too.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| FR-BR-11 | MUST | Merge a branch into the current branch from the branch picker's row menu, "Merge into <current>", offered for a local branch, a remote branch and a tag. It fast-forwards when possible, else makes a merge commit with git's default message; hooks run. It is refused before anything runs when an operation is in progress or HEAD is detached; local changes the merge would overwrite are refused with the stash-and-retry offer Pull has (FR-SYNC-09). Conflicts hand over to the conflict flow (FR-CONF).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| FR-BR-12 | MUST | Rebase the current branch onto a branch from the row menu, "Rebase <current> onto this". Merge commits in the branch are flattened; no other branch is moved. A branch already up to date gets a notice and nothing changes. Refusals and conflicts as for merge (FR-BR-11).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

## Update another branch in the background (UPD)

Bring a local branch up to date without checking it out.

| ID        | Prio | Requirement                                                                                                                                                                                                                  |
| --------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-UPD-01 | MUST | Update a local branch that is not checked out in any worktree to its upstream. No worktree's files are touched.                                                                                                              |
| FR-UPD-02 | MUST | Runs in the background. The app stays usable.                                                                                                                                                                                |
| FR-UPD-03 | MUST | Fast-forward only. If the branch has diverged, change nothing and report it.                                                                                                                                                 |
| FR-UPD-04 | MUST | A branch checked out in a worktree, or being rebased or bisected there, is not updated: before anything runs, the app says so, names that worktree and says what to do there: pull it, or finish the rebase or bisect first. |
| FR-UPD-05 | MUST | Report the result: updated (old → new, number of commits), already up to date, or failed with reason.                                                                                                                        |
| FR-UPD-06 | MUST | Update several selected branches in one action.                                                                                                                                                                              |
