# Glossary

One name per thing (QA-USE-03): the term in the first column, never the ones in the last.

| Term                                        | Meaning                                                                                                                                                                    | Not                             |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| repo                                        | A git repository. The recent repos are the ones opened before.                                                                                                             | project, folder                 |
| worktree                                    | One working folder of a repo: its main worktree or a linked one.                                                                                                           | workspace, checkout             |
| window                                      | A main app window. Several can be open, each on its own worktree (FR-WT-05) or on none yet (FR-WT-13).                                                                     |                                 |
| toolbar                                     | The bar of a window's main controls: the pickers, the sync controls, the jobs menu, Refresh, "Open in <editor>", Settings.                                                 | header                          |
| repo picker, worktree picker, branch picker | The three toolbar buttons that name the current repo, worktree and branch and open a searchable list of the others (FR-WT-13, FR-BR-09).                                   | workspace picker, selector      |
| sync controls                               | Fetch, Pull and Push in the toolbar.                                                                                                                                       |                                 |
| job                                         | A git action that runs in the background: fetch, pull, push, a branch update.                                                                                              | task, process                   |
| jobs menu                                   | The toolbar button that lists the running jobs (FR-UX-12).                                                                                                                 | jobs strip                      |
| log view                                    | The repo's commits as a list with the graph, and the filter bar.                                                                                                           | git graph, history              |
| graph                                       | The log view's column that draws branches, forks and merges.                                                                                                               |                                 |
| filter bar                                  | The log view's search and filter fields.                                                                                                                                   |                                 |
| selection                                   | The commits selected in the log view (FR-LOG-13); two selected commits form a comparison.                                                                                  |                                 |
| comparison                                  | Two compared commits, the from side (selected first) and the to side (selected second), and the files that differ; or a commit compared with the working tree (FR-CMP-04). | compare mode                    |
| commit detail view                          | The view with the selected commit's details and changed files, or the comparison.                                                                                          | details panel, commit details   |
| changes view                                | The view with the working tree's changes: the change list and the commit box.                                                                                              | changes panel, make commit view |
| change list                                 | The changes view's list of staged, unstaged, untracked and conflicted files.                                                                                               |                                 |
| commit box                                  | The changes view's commit controls: commit message, amend, push after commit, the Commit button.                                                                           | commit form                     |
| switch                                      | The row of tabs that picks the visible view when not all three fit side by side (FR-UX-08).                                                                                |                                 |
| diff window                                 | The separate window every file diff opens in (FR-DIFF-07).                                                                                                                 | compare window                  |
| diff view                                   | The diff inside the diff window: git's own diff, unified or side by side.                                                                                                  |                                 |
| hunk                                        | One block of changed lines, as git's diff cuts it.                                                                                                                         | chunk                           |
| notice                                      | A short message about an action's result that does not block the window.                                                                                                   | toast                           |
| editor                                      | The external editor the user configured, named in "Open in <editor>".                                                                                                      | IDE                             |
| app log                                     | The log file the app writes (FR-UX-02).                                                                                                                                    | command log                     |
| settings                                    | The app's settings and the dialog that edits them, opened from the toolbar (FR-UX-04).                                                                                     | preferences                     |
