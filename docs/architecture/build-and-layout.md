# Build, packaging, repository layout

- Wails v3 Taskfile builds. On Windows: first the `linux/amd64` core, then the GUI that embeds it.
- Run-time prerequisites: git; WebView2 (Windows); GTK4 + WebKitGTK 6.0 as system packages (Linux). The AppImage does not bundle WebKitGTK (QA-INST-01).
- Windows: single `.exe`, zipped, embedding the Linux core. Linux: AppImage first, `.deb` later. macOS: `.app` zipped, unsigned, labelled untested. No installer, no auto-update (QA-INST-03).
- Releases: GitHub Actions builds from a version tag and attaches artifacts and `SHA256SUMS` to a GitHub Release (QA-INST-02). Unsigned Windows binaries trigger SmartScreen; documented.
- Version and commit are baked into the binary and shown in "About".
- Repo files: `LICENSE` (BSD-3-Clause), `README.md` (install, first start, editor setup, known limits), `CONTRIBUTING.md` (build and test steps, the spec-driven flow), `CHANGELOG.md`.
- CI licence check for Go and JS dependencies against an allow-list (QA-OSS-01, TR-19).
- Nothing owner-specific in code or defaults except "default editor = the editor" (QA-OSS-04).

## Repository layout

```
/docs
  requirements.md      the only design docs in the repo (TR-32)
  architecture.md
CLAUDE.md              entry point for Claude sessions: rules + pointer to the plans dir
/cmd
  /nebegit             GUI app: shell with the core in-process
  /nebegit-core        pure-Go headless core for WSL: --stdio server; launcher when called with a path
/internal
  /core                core API (interface + DTOs + events)
  /remote              generated JSON-RPC client + dispatcher, WSL start/deployment
  /session             repo + worktree sessions
  /app                 Wails wiring (only Wails import), settings
  /git                 runner + parsers
  /graph
  /jobs
  /watch
  /settings
  /editor
  /services
  /buildinfo           version stamped at release build time
/frontend
  embed.go             package frontend: go:embed of dist/, handed to internal/app as fs.FS
  /bindings            generated by wails3, gitignored
  /src
    /stores
    /views             Log, Changes, Worktrees
    /components        CommitList, GraphCell, DiffView, FileTree, dialogs
/testdata              golden files
/build                 Wails Taskfiles and packaging assets per platform (generated by wails3, edited)
/tools/repocheck       test-only package: repository conventions (TR-23/24/25, QA-MNT-03)
/tools/mkrepo          builds test and benchmark repos
/tools/trace           requirement-ID traceability check (TR-30)
/tools/gencore         go generate: RPC client + dispatcher + shell facade from internal/core (TR-28)
/.github/workflows     ci.yml, release.yml
LICENSE  README.md  CONTRIBUTING.md  CHANGELOG.md
flake.nix  flake.lock  .envrc  .golangci.yml
Taskfile.yml           setup · test · lint · build · dev · ci (+ Wails tasks)
```

Milestones and the spec list: plans dir `ROADMAP.md`.
